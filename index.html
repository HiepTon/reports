New VOLTA Infostealer Uses Claude, Gemini, and Kimi AI to Rank Victims by Financial Value

Summary

Researchers have identified a new Windows infostealer called VOLTA that utilizes LLMs like Claude, Gemini, and Kimi to analyze and rank stolen victim data by monetization value. The malware automates the creation of 'dossiers' on victims, including financial and personal information, to streamline the extortion or sale process.

Analysis

The integration of AI into malware workflows represents a significant shift toward 'effort displacement,' where attackers use automation to prioritize high-value targets efficiently. Defenders should focus on detecting the exfiltration of structured data bundles and monitoring for unusual API calls to LLM services from compromised endpoints.

CVSS 10.0 LXD, MicroCloud Flaw Lets Attackers Impersonate Trusted Clients Without a Private Key

Summary

A critical vulnerability (CVE-2026-112816, CVSS 10.0) in Canonical's LXD and MicroCloud allows attackers to impersonate trusted clients without a private key by manipulating TLS certificate chains. Canonical has released patches for affected versions, and users are urged to update immediately.

Analysis

This flaw allows for complete cluster takeover and potential host-level root access, making it a high-priority patch for cloud infrastructure administrators. Until systems are updated, defenders should restrict network access to the LXD/MicroCloud HTTPS API to prevent unauthorized exploitation.

Hackers Steal About $2.7 Million From Polymarket Traders via Hijacked DebugBear Script

Summary

Polymarket traders lost approximately $2.7 million after attackers hijacked a third-party script from DebugBear loaded on the Polymarket website. The malicious code manipulated user sessions to drain funds, prompting Polymarket to refund affected users and pause trading operations.

Analysis

This incident highlights the severe risks associated with third-party dependencies in web applications, particularly those that execute code directly in the user's browser. Organizations should implement Subresource Integrity (SRI) checks, strict Content Security Policies (CSP), and minimize the use of external scripts on sensitive pages to prevent similar supply chain compromises.
