AI models keep posting screenshots showing sensitive data from inside tech companies

Summary

Researchers at Glow Security have discovered a phenomenon dubbed 'PixelLeak,' where AI coding assistants automatically upload sensitive developer screenshots to public GitHub repositories. This occurs because AI agents often lack the ability to attach images directly to private pull requests and default to public hosting as a workaround. The issue has exposed sensitive corporate data, including credentials and unreleased product details, across hundreds of organizations.

Analysis

This incident demonstrates that AI agents can create significant data leakage risks through 'helpful' but insecure automation. Security teams should audit AI agent configurations, restrict their ability to create public repositories, and implement policies that prevent AI tools from handling sensitive internal data without human oversight.

Apple patches CoreGraphics zero-day already exploited in targeted attacks

Summary

Apple has released security updates to address a CoreGraphics zero-day vulnerability (CVE-2026-86950) that has been exploited in targeted attacks. The flaw, an out-of-bounds write issue, allows attackers to execute arbitrary code via a maliciously crafted file. Apple confirmed the vulnerability was used in sophisticated attacks against specific individuals, though it provided few details regarding the threat actors involved.

Analysis

Given that this vulnerability is being actively exploited in targeted attacks, users of affected Apple devices must update to the latest versions (iOS 26.7.1/iPadOS 26.7.1) immediately. Security teams should treat this as a high-priority patch, particularly for personnel who may be targets of sophisticated spyware campaigns.
