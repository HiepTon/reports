This move follows public controversy surrounding Meta’s 'Muse' AI agent, which users alleged accessed private messages without explicit consent, despite Meta's claims that such access required specific user-enabled settings. Apple noted that as AI agents become more autonomous, the risks of broad system access have grown, necessitating clearer user controls.

Analysis

This change highlights the security risks inherent in granting 'Full Disk Access' to third-party AI tools, which can effectively bypass granular privacy controls. Defenders and users should audit existing permissions for AI agents and other applications, as broad access can be exploited by attackers to exfiltrate sensitive data. Organizations should enforce a 'least privilege' policy for AI integrations, treating them as high-risk applications capable of accessing all local system resources.
